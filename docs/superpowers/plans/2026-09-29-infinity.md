# Strength of Infinity and the Shared Spell Framework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the *Strength of Infinity* spell (creative mode minus immortality), make every scroll single-use under one shared set of cast rules, let players scribe random scrolls from paper at an enchanting table, and generate all spell icons from one script.

**Architecture:** The business rules live in a pure core (`spell.rules`: `CastRules`, `ScrollDraw`, `InfinityAbilities`, `DeathRule`, plus the spell declarations), which has no Minecraft imports and is unit-, property- and mutation-tested. Thin Minecraft plumbing calls it: the scroll item, a per-tick ability sync, two death/respawn event handlers, and three small Mixins (effect cures and the enchanting menu on the common side, the enchanting tooltip on the client). The server owns every piece of state; the client only reads vanilla-synced effects, abilities and menu data. No custom packets.

**Tech Stack:** Minecraft 26.3, NeoForge 26.3.0.23-beta (ModDevGradle 2.0.147), Java 25, MixinExtras 0.5.5 (bundled), JUnit 5.14.4, jqwik 1.10.1, ArchUnit 1.5.1, AssertJ 3.27.7, Error Prone 2.50.0, Spotless 8.10.3 + palantir-java-format 2.100.0, PIT 1.30.0, Python 3 stdlib (`unittest`) for the icon script, pre-commit, gitlint, markdownlint-cli2.

**Spec:** [`docs/superpowers/specs/2026-09-29-infinity-design.md`](../specs/2026-09-29-infinity-design.md)

## Global Constraints

- Minecraft **26.3**; NeoForge **26.3.0.23-beta**, pinned exactly; Java **25**. Mod ID **`spellcraft`**; base package **`io.github.willrieske.spellcraft`**.
- Tiers: **`NOOB`, `STARTER`, `GOOD`, `AMAZING`, `EXTREME`**. Top tier = **`EXTREME`**. Upside-Down = **`STARTER`**, Infinity = **`EXTREME`**.
- Every scroll is **single-use**, including in creative and during Infinity: removed with `stack.shrink(1)`, never `ItemStack.consume`. Scroll stack size **16**.
- Refusal message (action bar): **"Scroll not needed; already have effect!"**; a refused use keeps the scroll and returns `InteractionResult.FAIL`.
- Infinity: casts in **survival and adventure**; refused in **creative** and **while already active** (sneak + use too). Infinite duration. Only **death** and **`/effect clear`** remove it; milk and totems do not. `invulnerable` is never granted.
- Infinity death: **no item drops**; **armor deleted**; **hotbar, main inventory and offhand restored** in the same slots on respawn; Curse of Vanishing items deleted; **XP as vanilla**; `keepInventory` on → vanilla behaviour.
- Scribing: paper (`#spellcraft:scribable`) + lapis at an enchanting table; options cost **1/2/3 lapis and 1/2/3 levels**; server config `scribing.topTierChancePercent` = exactly **3** integers, each **0–100**, default **[25, 50, 75]**. `instabuild` players scribe free (vanilla waiver).

- No networking code of our own. Mixins only where no event exists; every injector has **`require = 1`**; handlers are thin and call shared code.
- ArchUnit rule 1: nothing outside `io.github.willrieske.spellcraft.client` references client-only code. Rule 2 (purity): `client.upsidedown` and `spell.rules` reference only `java..` and themselves.

## Deviations from the spec (verified against the 26.3 sources on 2026-09-29)

Task 1 records the evidence in `docs/api-notes.md` §10–§17.

1. **26.3 NeoForge has no effect-cure API.** There is no `EffectCure`/`fillEffectCures`. Milk and the totem both run `ClearAllStatusEffectsConsumeEffect.apply` → `LivingEntity.removeAllEffects()`, and `/effect clear` calls the same `removeAllEffects()` directly. `MobEffectEvent.Remove` carries no cause, so an event can't tell them apart. Instead: a marker interface `CureImmune` on `InfinityEffect`, and a common Mixin on `ClearAllStatusEffectsConsumeEffect.apply` that removes every *curable* effect when an immune one is active.
2. **Death stash is read from `PlayerEvent.Clone#getOriginal()`**, and neither attachment uses `copyOnDeath`. The dead player still holds its stash when the clone fires, and `restoreFrom` resets abilities from the game mode (`ServerPlayer.java:1723`), so the new player starts unmarked with survival flags. G4 still asserts that outcome.
3. **Duration stays on the Minecraft-facing `Spell`** (`IntSupplier`), not on `SpellRules`: the pure core never needs it. `SpellRules` gains a `name` so declarations are pure and testable (`SpellDeclarations`). `CastOutcome` is an **enum** (exhaustive `switch`), which gives the spec's "sealed type" guarantee more simply.
4. **Two Mixin configs.** A Mixin config has one root package, and every class under it is treated as a Mixin. So: `spellcraft.mixins.json` (common, package `…spellcraft.mixin`) and `spellcraft.client.mixins.json` (client, package `…spellcraft.client.mixin`). The spec's "new ArchUnit rule: common Mixins reference no client classes" is **already enforced by rule 1** (`…spellcraft.mixin` is outside `client`), so no new rule is added.
5. **GameTests use our own mock player** (`MockPlayers.inLevel`). Vanilla's `makeMockServerPlayerInLevel()` overrides `gameMode()` to always return `CREATIVE` (`GameTestHelper.java:397-409`), and the cast rules depend on the game mode.
6. **Icon test I1 is "every glyph pixel lands on the paper" (any non-transparent sheet pixel)**, not "on a fill pixel". The approved Upside-Down arrow already covers two rim pixels at y = 4; keeping its exact art keeps the scroll PNG byte-identical.
7. **The scribing options look enabled without a Mixin.** NeoForge greys out an option only when `enchantClue == -1` (`EnchantmentScreen.java:114`), so the server sets `enchantClue = 0`. The client Mixin only replaces the tooltip, and it must wrap vanilla's tooltip call: `GuiGraphicsExtractor` keeps the **first** tooltip set per frame (`:1173`). The screen's top edge comes from NeoForge's public `AbstractContainerScreen#getTopPos()`, so no access transformer is needed.
8. **`ScrollDraw` takes a `Dice` (`int below(int bound)`)**, not `java.util.random.RandomGenerator`: Minecraft's `RandomSource` does not implement it.
9. **The `slotsChanged` hook cancels on both sides.** Vanilla's client branch would zero the costs for a non-enchantable item, and the server only resends a data slot when its own value changes.
10. **GameTest G9 is a codec round-trip** of the stash with registry-aware NBT ops (what the save file uses), not a full player save/reload. **P2 (stash → restore gives back the slots)** is covered by GameTest G2, since restore is plumbing, not pure core.
11. **`/effect clear` tests call `removeAllEffects()`**, which is exactly what `EffectCommands.java:211` runs; all mock players share one name, so a command selector can't target one.

```java
                    .as(outcome.name())
                    .isEqualTo(outcome != CastOutcome.REFUSE);
        }
    }
```

```java
package io.github.willrieske.spellcraft.spell.rules;

/** The one decision every scroll use goes through. Runs on both sides; only the server acts on it. */
public final class CastRules {
    private CastRules() {}

    /**
     * Decides what a scroll use does, applying the spec's rules in priority order (first match wins):
     * creative-redundant refusal, sneak-dispel, refuse-on-recast, refresh, cast.
     *
     * @param rules the spell's business rules
     * @param caster the player's current sneak, effect and mode state
     * @return the outcome to apply and the feedback to give
     */
    public static CastOutcome decide(SpellRules rules, Caster caster) {
        if (caster.mode() == PlayerMode.CREATIVE && rules.redundantInCreative()) {
            return CastOutcome.REFUSE;
        }
        if (caster.effectActive()) {
            if (caster.sneaking() && rules.dispellable()) {
                return CastOutcome.DISPEL;
            }
            return rules.recast() == SpellRules.Recast.REFUSE ? CastOutcome.REFUSE : CastOutcome.REFRESH;
        }
        return CastOutcome.CAST;
    }
}
```

```java
final class ScriptedDice implements ScrollDraw.Dice {
    private final Deque<Integer> rolls;

    ScriptedDice(Integer... rolls) {
        this.rolls = new ArrayDeque<>(List.of(rolls));

        int roll = Objects.requireNonNull(rolls.poll(), "dice script exhausted");
        if (roll < 0 || roll >= bound) {
            throw new IllegalStateException("scripted roll " + roll + " outside [0, " + bound + ")");
        }
        return roll;
    }

    boolean exhausted() {
        return rolls.isEmpty();
```

```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.List;
import java.util.Objects;

/**
 * Scribing's draw (spec §5): roll the option's top-tier chance, then pick evenly within the chosen pool. An
 * empty pool falls back to the other one.
 */
public final class ScrollDraw {
    /** The enchanting table's three options; option {@code n} costs {@code n + 1} lapis and levels. */
    public static final int OPTIONS = 3;

    private static final int PERCENT = 100;

    /** A source of rolls; {@code below(bound)} returns a value in {@code [0, bound)}. */
    @FunctionalInterface
    public interface Dice {
        int below(int bound);
    }

    public record Candidate<S>(S spell, SpellTier tier) {
        public Candidate {
            Objects.requireNonNull(spell, "spell");
            Objects.requireNonNull(tier, "tier");
        }
    }

    private ScrollDraw() {}

    public static <S> void requireCandidates(List<Candidate<S>> candidates) {
        if (candidates.isEmpty()) {
            throw new IllegalArgumentException("scribing needs at least one spell to draw from");
        }
    }

    public static void requireChances(List<Integer> topTierChancePercent) {
        if (topTierChancePercent.size() != OPTIONS) {
            throw new IllegalArgumentException(
                    "expected " + OPTIONS + " top-tier chances, got " + topTierChancePercent.size());
        }
        for (int chance : topTierChancePercent) {
            if (chance < 0 || chance > PERCENT) {
                throw new IllegalArgumentException("top-tier chance must be 0-100, got " + chance);
            }
        }
    }

    /** Rolls against {@code topTierChancePercent[option]}, then picks evenly within the chosen pool (spec §5). */
    public static <S> S draw(
            int option, List<Candidate<S>> candidates, List<Integer> topTierChancePercent, Dice dice) {
        requireCandidates(candidates);
        requireChances(topTierChancePercent);
        if (option < 0 || option >= OPTIONS) {
            throw new IllegalArgumentException("option must be 0-" + (OPTIONS - 1) + ", got " + option);
        }
        List<S> top = candidates.stream()
                .filter(c -> c.tier().isTop())
                .map(Candidate::spell)
                .toList();
        List<S> rest = candidates.stream()
                .filter(c -> !c.tier().isTop())
                .map(Candidate::spell)
                .toList();
        boolean wantTop = dice.below(PERCENT) < topTierChancePercent.get(option);
        List<S> pool = wantTop ? (top.isEmpty() ? rest : top) : (rest.isEmpty() ? top : rest);
        return pool.get(dice.below(pool.size()));
    }
}
```

```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.Objects;

/**
 * Which creative abilities Infinity should hold (spec §3). {@code invulnerable} is deliberately absent: Infinity
 * never grants immortality. The "mark" records that Infinity, not vanilla or another mod, set the flags.
 */
public final class InfinityAbilities {
    public enum Action {
        /** Set {@code mayfly} and {@code instabuild}; set the mark. */
        GRANT,
        /** Reset the flags to the game mode's defaults (stops flight where the mode can't fly); clear the mark. */
        REVOKE,
        /** Clear the mark only: creative and spectator own their flags. */
        RELEASE,
        NONE
    }

    public record State(PlayerMode mode, boolean hasInfinity, boolean marked, boolean mayfly, boolean instabuild) {
        public State {
            Objects.requireNonNull(mode, "mode");
        }
    }

    private InfinityAbilities() {}

    /** One action settles the state every tick (spec §3). */
    public static Action decide(State state) {
        boolean grantingMode = state.mode() == PlayerMode.SURVIVAL || state.mode() == PlayerMode.ADVENTURE;
        if (state.hasInfinity()) {
            if (grantingMode) {
                return state.marked() && state.mayfly() && state.instabuild() ? Action.NONE : Action.GRANT;
            }
            return state.marked() ? Action.RELEASE : Action.NONE;
        }
        return state.marked() ? Action.REVOKE : Action.NONE;
    }
}
```

```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.ArrayList;
import java.util.List;
import java.util.Objects;

/**
 * What an Infinity death does to each inventory slot (spec §4): armor and Curse of Vanishing items are deleted;
 * everything else is stashed for respawn, in place. With {@code keepInventory} on, vanilla keeps everything and
 * this rule sorts nothing.
 */
public final class DeathRule {
    public enum SlotKind {
        HOTBAR,
        MAIN,
        OFFHAND,
        /** Anything worn: the four armor slots, and vanilla's body-armor and saddle slots (docs/api-notes.md §12). */
        ARMOR
    }

    public record Slot(int index, SlotKind kind, boolean empty, boolean vanishing) {
        public Slot {
            Objects.requireNonNull(kind, "kind");
        }
    }

    public record Sorted(List<Integer> stash, List<Integer> delete) {
        public static final Sorted NOTHING = new Sorted(List.of(), List.of());

        public Sorted {
            stash = List.copyOf(stash);
            delete = List.copyOf(delete);
        }
    }

    private DeathRule() {}

    /**
     * Partitions non-empty slots into indices to stash (in place) and indices to delete (armor, Curse of Vanishing);
     * {@code keepInventory} sorts nothing.
     */
    public static Sorted sort(List<Slot> slots, boolean keepInventory) {
        if (keepInventory) {
            return Sorted.NOTHING;
        }
        List<Integer> stash = new ArrayList<>();
        List<Integer> delete = new ArrayList<>();
        for (Slot slot : slots) {
            if (slot.empty()) {
                continue;
            }
            if (slot.vanishing() || slot.kind() == SlotKind.ARMOR) {
                delete.add(slot.index());
            } else {
                stash.add(slot.index());
            }
        }
        return new Sorted(stash, delete);
    }
}
```

```python
def chunks(png: bytes) -> list[tuple[bytes, bytes]]:
    """Split a PNG into (type, data) chunks, checking every CRC."""
    assert png.startswith(PNG_SIGNATURE), "bad PNG signature"
    out, pos = [], len(PNG_SIGNATURE)
    while pos < len(png):
        (length,) = struct.unpack(">I", png[pos : pos + 4])
        kind = png[pos + 4 : pos + 8]
        data = png[pos + 8 : pos + 8 + length]
        (crc,) = struct.unpack(">I", png[pos + 8 + length : pos + 12 + length])
        assert crc == zlib.crc32(kind + data) & 0xFFFFFFFF, f"bad CRC in {kind!r}"

    return out
```

```python
def glyph_pixels(spell: Spell, scale: int, offset: tuple[int, int]) -> frozenset[tuple[int, int]]:
    ox, oy = offset
    return frozenset(
        (ox + x * scale + dx, oy + y * scale + dy)
        for y, row in enumerate(spell.glyph)
        for x, cell in enumerate(row)
        if cell == "#"
        for dy in range(scale)

    height = len(spell.glyph) * EFFECT_SCALE
    return (EFFECT_SIZE - width) // 2, (EFFECT_SIZE - height) // 2


def chunk(kind: bytes, data: bytes) -> bytes:
    body = kind + data
    return struct.pack(">I", len(data)) + body + struct.pack(">I", zlib.crc32(body) & 0xFFFFFFFF)


def encode_png(size: int, pixel_at) -> bytes:
    rows = b"".join(b"\x00" + b"".join(bytes(pixel_at(x, y)) for x in range(size)) for y in range(size))
    return (
        b"\x89PNG\r\n\x1a\n"
        + chunk(b"IHDR", struct.pack(">IIBBBBB", size, size, 8, 6, 0, 0, 0))
        + chunk(b"IDAT", zlib.compress(rows, 9))
        + chunk(b"IEND", b"")
    )


def scroll_png(spell: Spell) -> bytes:
    ink = glyph_pixels(spell, 1, spell.origin)
    return encode_png(SCROLL_SIZE, lambda x, y: spell.ink if (x, y) in ink else PALETTE.get(SHEET[y][x], CLEAR))


def effect_png(spell: Spell) -> bytes:
    ink = glyph_pixels(spell, EFFECT_SCALE, effect_offset(spell))
    return encode_png(EFFECT_SIZE, lambda x, y: spell.ink if (x, y) in ink else CLEAR)


def outputs(spell: Spell) -> dict[Path, bytes]:
    return {
        TEXTURES / "item" / f"{spell.id}_scroll.png": scroll_png(spell),
        TEXTURES / "mob_effect" / f"{spell.id}.png": effect_png(spell),
    }


def main() -> None:
    for spell in SPELLS:
        for path, png in outputs(spell).items():
            path.parent.mkdir(parents=True, exist_ok=True)
            path.write_bytes(png)


if __name__ == "__main__":
    main()
```

```java
        player.setItemInHand(InteractionHand.MAIN_HAND, stack);
    }

        return player.getMainHandItem().getCount();
    }

    public static MobEffectInstance requireEffect(
            GameTestHelper helper, ServerPlayer player, Holder<MobEffect> effect) {
        MobEffectInstance instance = player.getEffect(effect);
        if (instance == null) {
            throw helper.assertionException("expected " + effect.getRegisteredName() + " to be active");
        }
        return instance;
    }

    /** Runs {@code body} with a global server config value set to {@code temporary}, restoring it afterwards. */
    public static <T> void withConfig(ModConfigSpec.ConfigValue<T> value, T temporary, Runnable body) {
        T saved = value.get();
        value.set(temporary);
        try {
            body.run();
        } finally {
            value.set(saved);
        }
    }
```

```java
     * Test functions by environment, in registration order. Batches run one after another, so a test that
     * mutates global state (config, game rules) gets an environment of its own.
     */

            BY_ENVIRONMENT = new LinkedHashMap<>();

        UpsideDownGameTests.registerAll();
    }

    private SpellcraftGameTests() {}

    static void add(String environment, String name, Consumer<GameTestHelper> body) {
        BY_ENVIRONMENT
                .computeIfAbsent(environment, e -> new ArrayList<>())
                .add(TEST_FUNCTIONS.register(name, () -> body));
    }

    @SubscribeEvent
    public static void register(RegisterGameTestsEvent event) {
        BY_ENVIRONMENT.forEach((environment, functions) -> {
            Holder<TestEnvironmentDefinition<?>> holder = event.registerEnvironment(Spellcraft.id(environment));
            functions.forEach(function -> test(event, holder, function));
        });
    }

    private static void test(
            RegisterGameTestsEvent event,
            Holder<TestEnvironmentDefinition<?>> environment,
            DeferredHolder<Consumer<GameTestHelper>, Consumer<GameTestHelper>> function) {
        event.registerTest(
                function.getId(),
                new FunctionGameTestInstance(
                        function.getKey(), new TestData<>(environment, EMPTY_STRUCTURE, MAX_TICKS, 0, true)));
    }
```

```java
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.level.GameType;

/** Maps vanilla's game mode onto the pure core's {@link PlayerMode}. */
public final class PlayerModes {
    private PlayerModes() {}

    public static PlayerMode of(Player player) {
        return of(player.gameMode());
    }

    /**
     * A client player whose tab-list entry hasn't arrived has no game mode yet; treat it as survival. This only
     * affects the client's swing prediction: the server decides.

    static PlayerMode of(@Nullable GameType type) {
        if (type == null) {
            return PlayerMode.SURVIVAL;
        }
        return switch (type) {
            case SURVIVAL -> PlayerMode.SURVIVAL;
            case ADVENTURE -> PlayerMode.ADVENTURE;
            case CREATIVE -> PlayerMode.CREATIVE;
            case SPECTATOR -> PlayerMode.SPECTATOR;
        };
```

```java
import net.minecraft.core.particles.ParticleTypes;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.sounds.SoundSource;
import net.minecraft.world.entity.player.Player;

/** A used scroll withers away: a puff of dark smoke at the caster's hand and a short fizzle (docs/api-notes.md §17). */
final class ScrollFx {
    private static final int SMOKE_COUNT = 12;
    private static final double SMOKE_SPREAD = 0.15;
    private static final double SMOKE_SPEED = 0.01;
    private static final double HAND_REACH = 0.5;
    private static final double HAND_DROP = 0.3;

    private ScrollFx() {}

    static void wither(ServerLevel level, Player player) {
        Vec3 look = player.getLookAngle();
        double x = player.getX() + look.x * HAND_REACH;
        double y = player.getEyeY() - HAND_DROP + look.y * HAND_REACH;
        double z = player.getZ() + look.z * HAND_REACH;
        level.sendParticles(
                ParticleTypes.LARGE_SMOKE, x, y, z, SMOKE_COUNT, SMOKE_SPREAD, SMOKE_SPREAD, SMOKE_SPREAD, SMOKE_SPEED);
        level.playSound(
                null,
                player.getX(),
                player.getY(),
```

```java
import io.github.willrieske.spellcraft.spell.rules.CastOutcome;
import io.github.willrieske.spellcraft.spell.rules.CastRules;
import io.github.willrieske.spellcraft.spell.rules.Caster;
import net.minecraft.network.chat.Component;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.world.InteractionHand;
import net.minecraft.world.InteractionResult;
import net.minecraft.world.effect.MobEffectInstance;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.item.Item;
import net.minecraft.world.level.Level;

/**
 * A single-use scroll for one {@link Spell}. Every use goes through {@link CastRules}; both sides decide (so a
 * refusal shows no swing), and only the server changes state.
 */
public class SpellScrollItem extends Item {
    public static final String REFUSED_KEY = "message.spellcraft.scroll_not_needed";

    private final Spell spell;

    public SpellScrollItem(Spell spell, Item.Properties properties) {
        super(properties);
        this.spell = spell;
    }

    public Spell spell() {
        return spell;
    }

    @Override
    public InteractionResult use(Level level, Player player, InteractionHand hand) {
        CastOutcome outcome = CastRules.decide(
                spell.rules(),
                new Caster(player.isShiftKeyDown(), player.hasEffect(spell.effect()), PlayerModes.of(player)));
        if (!outcome.consumesScroll()) {
            if (!level.isClientSide()) {
                player.sendOverlayMessage(Component.translatable(REFUSED_KEY));
            }
            return InteractionResult.FAIL;
        }
        if (level instanceof ServerLevel serverLevel) {
            apply(outcome, player);
            // shrink, not consume: consume skips players with instabuild (creative, Infinity), and a scroll is
            // single-use for everyone.
            player.getItemInHand(hand).shrink(1);
            ScrollFx.wither(serverLevel, player);
        }
        return InteractionResult.SUCCESS;
    }

    private void apply(CastOutcome outcome, Player player) {
        switch (outcome) {
                // Particles hidden (visible = false): other players see nothing unusual; icon shown. addEffect on an
                // active effect with a longer duration refreshes it without a remove/add pair, so the client sees
                // no gap.
            case CAST, REFRESH ->
                player.addEffect(new MobEffectInstance(
                        spell.effect(), spell.durationTicks().getAsInt(), 0, false, false, true));
            case DISPEL -> player.removeEffect(spell.effect());
            case REFUSE -> throw new IllegalStateException("REFUSE keeps the scroll and never reaches apply");
        }
    }
}
```

```java
package io.github.willrieske.spellcraft.effect;

import java.util.List;
import net.minecraft.core.Holder;
import net.minecraft.world.effect.MobEffect;
import net.minecraft.world.effect.MobEffectInstance;
import net.minecraft.world.entity.LivingEntity;

/** "Clear all effects" from an item (milk, totem) that spares {@link CureImmune} effects. */
public final class Cures {
    private Cures() {}

    /** Whether {@code entity} currently carries any {@link CureImmune} effect. */
    public static boolean hasCureImmune(LivingEntity entity) {
        return entity.getActiveEffects().stream().anyMatch(e -> isImmune(e.getEffect()));
    }

    /** Like {@code removeAllEffects()} but keeps immune effects; each removal still fires NeoForge's event. */
    public static boolean removeAllCurable(LivingEntity entity) {
        if (entity.level().isClientSide()) {
            return false;
        }
        List<Holder<MobEffect>> curable = entity.getActiveEffects().stream()
                .map(MobEffectInstance::getEffect)
                .filter(effect -> !isImmune(effect))
                .toList();
        boolean removed = false;
        for (Holder<MobEffect> effect : curable) {
            removed |= entity.removeEffect(effect);
        }
        return removed;
    }

    private static boolean isImmune(Holder<MobEffect> effect) {
        return effect.value() instanceof CureImmune;
    }
}
```

```java
package io.github.willrieske.spellcraft.infinity;

import io.github.willrieske.spellcraft.Spellcraft;
import io.github.willrieske.spellcraft.effect.ModEffects;
import io.github.willrieske.spellcraft.spell.PlayerModes;
import io.github.willrieske.spellcraft.spell.rules.InfinityAbilities;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.world.entity.player.Abilities;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.tick.PlayerTickEvent;

/**
 * Keeps each player's creative abilities in line with Infinity, every server tick. Vanilla's abilities packet
 * syncs the client, which then opens the creative inventory by itself (docs/api-notes.md §11).
 */
@EventBusSubscriber(modid = Spellcraft.MODID)
public final class InfinityAbilitySync {
    private InfinityAbilitySync() {}

    @SubscribeEvent
    public static void onPlayerTick(PlayerTickEvent.Post event) {
        if (event.getEntity() instanceof ServerPlayer player) {
            sync(player);
        }
    }

    /** Public so GameTests can run one sync without waiting for a tick. */
    @SuppressWarnings("deprecation") // Abilities#mayfly is @Deprecated (-Xlint:all -Werror). Granting/revoking it
    // directly is the per-flag control we need: IPlayerExtension#mayFly() only reads, and folds in
    // CREATIVE_FLIGHT-attribute flight that we neither grant nor revoke.
    public static void sync(ServerPlayer player) {
        Abilities abilities = player.getAbilities();
        InfinityAbilities.Action action = InfinityAbilities.decide(new InfinityAbilities.State(
                PlayerModes.of(player),
                player.hasEffect(ModEffects.INFINITY),
                player.getData(InfinityAttachments.GRANTED),
                abilities.mayfly,
                abilities.instabuild));
        switch (action) {
            case GRANT -> {
                abilities.mayfly = true;
                abilities.instabuild = true;
                player.setData(InfinityAttachments.GRANTED, true);
                player.onUpdateAbilities();
            }
            case REVOKE -> {
                // The mode's defaults; survival and adventure also stop flight.
                player.gameMode().updatePlayerAbilities(abilities);
                player.setData(InfinityAttachments.GRANTED, false);
                player.onUpdateAbilities();
            }
            case RELEASE -> player.setData(InfinityAttachments.GRANTED, false);
            case NONE -> {}
        }
    }
}
```

```java
package io.github.willrieske.spellcraft.infinity;

import com.mojang.logging.LogUtils;
import io.github.willrieske.spellcraft.Spellcraft;
import io.github.willrieske.spellcraft.effect.ModEffects;
import io.github.willrieske.spellcraft.spell.rules.DeathRule;
import java.util.ArrayList;
import java.util.List;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.world.entity.player.Inventory;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.enchantment.EnchantmentEffectComponents;
import net.minecraft.world.item.enchantment.EnchantmentHelper;
import net.minecraft.world.level.gamerules.GameRules;
import net.neoforged.bus.api.EventPriority;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.entity.living.LivingDeathEvent;
import net.neoforged.neoforge.event.entity.player.PlayerEvent;
import org.slf4j.Logger;

/**
 * Infinity's death rule (spec §4): on death, stash what {@link DeathRule} keeps and empty the inventory, so vanilla
 * drops nothing; on respawn, put the stash back in the same slots. XP is untouched (vanilla).
 */
@EventBusSubscriber(modid = Spellcraft.MODID)
public final class InfinityDeath {
    private static final Logger LOGGER = LogUtils.getLogger();

    private InfinityDeath() {}

    /** Lowest priority and not for cancelled events: every mod that might cancel the death has already run. */
    @SubscribeEvent(priority = EventPriority.LOWEST)
    public static void onDeath(LivingDeathEvent event) {
        if (event.getEntity() instanceof ServerPlayer player && player.hasEffect(ModEffects.INFINITY)) {
            stash(player, player.level().getGameRules().get(GameRules.KEEP_INVENTORY));
        }
    }

    @SubscribeEvent
    public static void onClone(PlayerEvent.Clone event) {
        if (event.isWasDeath()) {
            restore(event.getEntity(), event.getOriginal());
        }
    }

    static void stash(Player player, boolean keepInventory) {
        Inventory inventory = player.getInventory();
        List<DeathRule.Slot> slots = new ArrayList<>();
        for (int i = 0; i < inventory.getContainerSize(); i++) {
            ItemStack stack = inventory.getItem(i);
            boolean vanishing =
                    !stack.isEmpty() && EnchantmentHelper.has(stack, EnchantmentEffectComponents.PREVENT_EQUIPMENT_DROP);
            slots.add(new DeathRule.Slot(i, kindOf(i), stack.isEmpty(), vanishing));
        }
        if (keepInventory) {
            return; // vanilla keeps everything; DeathRule sorts nothing
        }
        DeathRule.Sorted sorted = DeathRule.sort(slots, false);
        List<DeathStash.Entry> entries = sorted.stash().stream()
                .map(slot -> new DeathStash.Entry(slot, inventory.getItem(slot).copy()))
                .toList();
        player.setData(InfinityAttachments.STASH, new DeathStash(entries));
        // Stashed items are now held by the stash; deleted items (armor, Vanishing) simply go.
        for (int i = 0; i < inventory.getContainerSize(); i++) {
            inventory.setItem(i, ItemStack.EMPTY);
        }
    }

    /**
     * Puts {@code original}'s death stash back into {@code target}'s inventory, then clears it. Never throws for a
     * corrupt or out-of-range entry: logs a warning and skips it, so a bad stash can't crash the respawn.
     */
    public static void restore(Player target, Player original) {
        DeathStash stash = original.getData(InfinityAttachments.STASH);
        if (stash.entries().isEmpty()) {
            return;
        }
        Inventory inventory = target.getInventory();
        for (DeathStash.Entry entry : stash.entries()) {
            if (entry.slot() < 0 || entry.slot() >= inventory.getContainerSize()) {
                LOGGER.warn(
                        "Dropping stashed {} for {}: slot {} is out of range",
                        entry.stack(),
                        target.getPlainTextName(),
                        entry.slot());
                continue;
            }
            inventory.setItem(entry.slot(), entry.stack().copy());
        }
        original.removeData(InfinityAttachments.STASH);
    }

    /** Vanilla's layout (docs/api-notes.md §12): 0-8 hotbar, 9-35 main, 40 offhand, the rest worn. */
    private static DeathRule.SlotKind kindOf(int slot) {
        if (slot < Inventory.getSelectionSize()) {
            return DeathRule.SlotKind.HOTBAR;
        }
        if (slot < Inventory.INVENTORY_SIZE) {
            return DeathRule.SlotKind.MAIN;
        }
        if (slot == Inventory.SLOT_OFFHAND) {
            return DeathRule.SlotKind.OFFHAND;
        }
        return DeathRule.SlotKind.ARMOR;
    }
}
```

```java
import io.github.willrieske.spellcraft.Spellcraft;
import io.github.willrieske.spellcraft.config.ServerConfig;

import net.minecraft.core.registries.Registries;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.sounds.SoundSource;
import net.minecraft.stats.Stats;
import net.minecraft.tags.TagKey;
import net.minecraft.world.Container;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.inventory.EnchantmentMenu;
import net.minecraft.world.item.Item;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.level.Level;

/**
 * Scribing paper into a random scroll at an enchanting table (spec §5). Called from {@code EnchantmentMenuMixin};
 * vanilla's own checks (lapis, levels, the instabuild waiver) have already run.
 */
public final class Scribing {
    public static final TagKey<Item> SCRIBABLE = TagKey.create(Registries.ITEM, Spellcraft.id("scribable"));

    /** Any value but -1: NeoForge's screen greys out an option whose clue is -1 (docs/api-notes.md §15). */
    private static final int CLUE = 0;

    private Scribing() {}

    public static boolean isScribable(ItemStack stack) {
        return !stack.isEmpty() && stack.is(SCRIBABLE);
    }

    public static List<ScrollDraw.Candidate<Spell>> candidates() {
        return Spells.ALL.stream()
                .map(spell -> new ScrollDraw.Candidate<>(spell, spell.rules().tier()))
                .toList();
    }

    /** Server: show the three options. The odds ride in {@code levelClue}, which vanilla syncs to the client. */
    public static void offer(EnchantmentMenu menu) {
        List<Integer> chances = ServerConfig.scribingTopTierChances();
        for (int option = 0; option < ScrollDraw.OPTIONS; option++) {
            menu.costs[option] = option + 1;
            menu.enchantClue[option] = CLUE;
            menu.levelClue[option] = chances.get(option);
        }
        menu.broadcastChanges();
    }

    /** Server: take the cost, draw a spell, and swap the paper for its scroll. */
    public static void scribe(Player player, int option, Container slots, Level level, BlockPos pos) {
        int cost = option + 1;
        ItemStack lapis = slots.getItem(1);
        player.onEnchantmentPerformed(slots.getItem(0), cost);
        Spell spell = ScrollDraw.draw(
                option, candidates(), ServerConfig.scribingTopTierChances(), level.getRandom()::nextInt);
        slots.setItem(0, ModItems.scrollFor(spell));
        // consume, not shrink: vanilla's waiver leaves instabuild players' lapis alone.
        lapis.consume(cost, player);
        if (lapis.isEmpty()) {
            slots.setItem(1, ItemStack.EMPTY);
        }
        player.awardStat(Stats.ENCHANT_ITEM);
        slots.setChanged();
        level.playSound(
                null,
                pos,
                SoundEvents.ENCHANTMENT_TABLE_USE,
                SoundSource.BLOCKS,
                1.0F,
                level.getRandom().nextFloat() * 0.1F + 0.9F);
    }
}
```

```java
    @SuppressWarnings("UnusedMethod") // invoked by Mixin at runtime, not by Java code
    private void spellcraft$offerScribing(Container container, CallbackInfo ci) {
        if (container == enchantSlots && Scribing.isScribable(enchantSlots.getItem(0))) {
            access.execute((level, pos) -> Scribing.offer((EnchantmentMenu) (Object) this));
            // Cancel on both sides: vanilla's client branch would zero the costs for a non-enchantable item, and
            // the server only resends a data slot when its own value changes.
            ci.cancel();
        }
    }

    /** Vanilla's checks (lapis, levels, instabuild waiver) have run; only the apply step is swapped. */
    @WrapOperation(
            method = "clickMenuButton",
            at =
                    @At(
                            value = "INVOKE",
                            target =
                                    "Lnet/minecraft/world/inventory/ContainerLevelAccess;execute(Ljava/util/function/BiConsumer;)V"),
            require = 1)
    @SuppressWarnings("UnusedMethod") // invoked by Mixin at runtime, not by Java code
    private void spellcraft$scribe(
            ContainerLevelAccess instance,
            BiConsumer<Level, BlockPos> vanillaApply,
            Operation<Void> original,
            @Local(argsOnly = true) Player player,
            @Local(argsOnly = true) int buttonId) {
        if (!Scribing.isScribable(enchantSlots.getItem(0))) {
            original.call(instance, vanillaApply);
            return;
        }
        instance.execute((level, pos) -> {
            Scribing.scribe(player, buttonId, enchantSlots, level, pos);
            enchantmentSeed.set(player.getEnchantmentSeed());
            ((EnchantmentMenu) (Object) this).slotsChanged(enchantSlots);
        });
    }
}
```

```java
package io.github.willrieske.spellcraft.client;

import java.util.ArrayList;
import java.util.List;
import net.minecraft.ChatFormatting;
import net.minecraft.client.player.LocalPlayer;
import net.minecraft.network.chat.CommonComponents;
import net.minecraft.network.chat.Component;
import net.minecraft.world.inventory.EnchantmentMenu;

/** The enchanting-table tooltip for a scribing option (spec §5). Vanilla's cost lines, our first two lines. */
public final class ScribingTooltip {
    /**
     * Vanilla's hover test is {@code isHovering(60, 14 + 19 * i, 108, 17, …)}, which pads each 17 px box by 1 px, so
     * row {@code i} covers {@code [13 + 19 * i, 32 + 19 * i)} below the screen top: three contiguous 19 px bands.
     */
    private static final int FIRST_BAND = 13;

    private static final int ROW_PITCH = 19;
    private static final int OPTIONS = 3;

    private ScribingTooltip() {}

    /** Which option the mouse is over, or -1. Agrees with vanilla's hover test on every pixel (no edge flicker). */
    public static int optionAt(int mouseY, int topPos) {
        int y = mouseY - topPos - FIRST_BAND;
        if (y < 0) {
            return -1;
        }
        int option = y / ROW_PITCH;
        return option < OPTIONS ? option : -1;
    }

    public static List<Component> lines(EnchantmentMenu menu, int option, LocalPlayer player) {
        List<Component> lines = new ArrayList<>();
        lines.add(Component.translatable("container.spellcraft.scribe").withStyle(ChatFormatting.WHITE));
        lines.add(Component.translatable("container.spellcraft.scribe.chance", menu.levelClue[option])
                .withStyle(ChatFormatting.LIGHT_PURPLE));
        if (player.hasInfiniteMaterials()) {
            return lines;
        }
        lines.add(CommonComponents.EMPTY);
        int cost = option + 1;
        if (player.experienceLevel < menu.costs[option]) {
            lines.add(Component.translatable("container.enchant.level.requirement", menu.costs[option])
                    .withStyle(ChatFormatting.RED));
            return lines;
        }
        Component lapis = cost == 1
                ? Component.translatable("container.enchant.lapis.one")
                : Component.translatable("container.enchant.lapis.many", cost);
        lines.add(lapis.copy()
                .withStyle(menu.getGoldCount() >= cost ? ChatFormatting.GRAY : ChatFormatting.RED));
        Component levels = cost == 1
                ? Component.translatable("container.enchant.level.one")
                : Component.translatable("container.enchant.level.many", cost);
        lines.add(levels.copy().withStyle(ChatFormatting.GRAY));
        return lines;
    }
}
```

```java
import com.llamalad7.mixinextras.injector.wrapoperation.Operation;
import com.llamalad7.mixinextras.injector.wrapoperation.WrapOperation;

import net.minecraft.client.gui.screens.inventory.EnchantmentScreen;

import net.minecraft.world.inventory.EnchantmentMenu;

import org.spongepowered.asm.mixin.injection.At;

/**
 * Replaces the enchanting tooltip while paper is being scribed (docs/api-notes.md §15). The tooltip must be swapped
 * at vanilla's call, because the first tooltip set in a frame wins. {@code require = 1}.
 */
@Mixin(EnchantmentScreen.class)
abstract class EnchantmentScreenMixin {
    @WrapOperation(
            method = "extractRenderState",
            at =
                    @At(
                            value = "INVOKE",
                            target =
                                    "Lnet/minecraft/client/gui/GuiGraphicsExtractor;setComponentTooltipForNextFrame(Lnet/minecraft/client/gui/Font;Ljava/util/List;II)V"),
            require = 1)
    @SuppressWarnings("UnusedMethod") // invoked by Mixin at runtime, not by Java code
    private void spellcraft$scribingTooltip(
            GuiGraphicsExtractor graphics,
            Font font,
            List<Component> lines,
            int mouseX,
            int mouseY,
            Operation<Void> original) {
        EnchantmentScreen screen = (EnchantmentScreen) (Object) this;
        EnchantmentMenu menu = screen.getMenu();
        LocalPlayer player = Minecraft.getInstance().player;
        int option = ScribingTooltip.optionAt(mouseY, screen.getTopPos());
        if (player == null || option < 0 || !Scribing.isScribable(menu.getSlot(0).getItem())) {
            original.call(graphics, font, lines, mouseX, mouseY);
            return;
        }
        original.call(graphics, font, ScribingTooltip.lines(menu, option, player), mouseX, mouseY);
    }
}
```
