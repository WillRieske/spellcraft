# Strength of Evoking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the *Strength of Evoking* spell: with the effect on, **F** carpets a 13×13 square ahead of the player with evoker fangs and **V** summons three vexes, both sparing the caster and the caster's allies, with the evoker's own timings, raised arms and hand particles.

**Architecture:** The spell plugs into the existing framework (a `SpellRules` declaration, a `MarkerEffect`, a scroll, a glyph). New are: a shared ally rule (`spell.Allies`, with a `summoner` entity attachment) that Trailing now uses too; the mod's one custom packet, a client→server `EvokingRequest` the server validates; a per-player casting state (`spell.rules.EvokingCast`, pure) driven by `evoking.EvokingCaster` on the player tick; `evoking.Fangs` and `evoking.VexSummons` for the two performs; and client code under `client.evoking` that reads casting state from vanilla's synced effect-particle list (two short "casting" effects carry a mod particle type each) to raise the arms (a NeoForge enum-extended `ArmPose`) and draw the evoker's hand particles. Pure geometry and timing live in `spell.rules` (`FangSquare`, `VexRing`, `EvokerPose`, `EvokerSpell`).

**Tech Stack:** Minecraft 26.3, NeoForge 26.3.0.23-beta (ModDevGradle 2.0.147), Java 25, JUnit 5.14.4, jqwik 1.10.1, ArchUnit 1.5.1, AssertJ 3.27.7, Error Prone 2.50.0, Spotless 8.10.3 + palantir-java-format 2.100.0, PIT 1.30.0, Python 3 stdlib for the icon script, pre-commit, gitlint, markdownlint-cli2.

**Spec:** [`docs/superpowers/specs/2026-11-06-evoking-design.md`](../specs/2026-11-06-evoking-design.md)

## Global Constraints

- Minecraft **26.3**; NeoForge **26.3.0.23-beta**, pinned; Java **25**. Mod ID **`spellcraft`**; base package **`io.github.willrieske.spellcraft`**.
- Declaration: name **`evoking`**, tier **`AMAZING`**, recast **`REFUSE`**, **dispellable**, **not** redundant in creative, duration **`Spell.INFINITE`**. Effect **"Strength of Evoking"**, category **beneficial**, color **`0xD2F8EA`**, a `MarkerEffect` (milk-curable).
- Casting effects `casting_fangs` / `casting_vexes`: category **neutral**, color `0xD2F8EA`, particle = the matching mod particle type; applied with `amplifier 0, ambient false, visible true, showIcon false` for the spell's casting ticks.
- Evoker timings (spec §4): **warmup 20** ticks; fangs **casting 40**, **interval 100**; vexes **casting 100**, **interval 340**. No config.
- Fang square (spec §5): 13×13, half 6, center = `round(6·f/max(|fx|,|fz|))` from the facing vector `(−sin yaw, cos yaw)`, `Math.round`; 168 cells (the caster's excluded); delay = Chebyshev distance − 1. Target scan: the square's columns, feet y − 6 … feet y + 6; targets = `canBeSeenAsEnemy() && attackable()` and not the caster or an ally. Floor window top = max(feet, highest target) + 1, bottom = min(feet, lowest target) − 1.
- Vexes (spec §6): 3 per cast, offsets with Chebyshev distance 2 or 3 (40 cells), y + 1, `MOB_SUMMONED`, life `20·(30 + roll)` with `roll` in 0…89, bound origin = spawn block, summoner attachment, the caster's team if any, `FOLLOW_RANGE` **5**, one target goal (`NearestAttackableTargetGoal<LivingEntity>`, mustSee true, selector = `attackable() && summoner online in that level && !Allies.isAllyOf(summoner, target)`), installed on `EntityJoinLevelEvent`.
- Allies (spec §3): `Allies.isAllyOf(owner, other)` = `owner.isAlliedTo(other)` or `other` carries the `spellcraft:summoner` attachment with `owner`'s UUID or `other` is an `OwnableEntity` whose owner reference UUID is `owner`'s. `Allies.mayHaveAllies(other)` = team, `OwnableEntity`, `Allay`, or the attachment.
- Keys: `key.spellcraft.fangs` = `InputConstants.KEY_F` (9), `key.spellcraft.vexes` = `InputConstants.KEY_V` (25), `InputConstants.Type.KEYBOARD`, `KeyConflictContext.IN_GAME`, category `spellcraft:spells` (lang `key.category.spellcraft.spells`). **Never `GLFW.GLFW_KEY_*`**: 26.3 key codes are SDL scancodes.
- Packet: `spellcraft:evoking_request`, `playToServer`, registrar version `"1"`, server-thread handler; the server validates everything.
- Pure core (`spell.rules`): no `net.minecraft`/NeoForge/jspecify imports (ArchUnit rule 2 allows only `java..`), so use `Optional`, not `@Nullable`. Client-only code only under `client` (rule 1). Common code never references `client`.
- Error Prone runs with `-Werror`; suppress only with `@SuppressWarnings("<Check>")` plus a comment why (`ReferenceEquality` for entity identity, docs/api-notes.md §8; `UnusedMethod` for nothing here).
- **Unit test style:** new unit and jqwik test classes follow the methodology's *Unit test style* (`~/.claude/development-methodology.md`): a Javadoc per test ("When …, the method should …" then `<p>Method under test: {@link …}`), one `@Nested` class per method under test, `// Arrange` / `// Act` / `// Assert` sections except in one-statement tests. GameTests and additions to existing test files keep their file's current style.
- GameTests that place fangs or vexes register with **`maxTicks 200, padding 13`** through the new `SpellcraftGameTests.add(environment, name, maxTicks, padding, body)` overload; the padded box is cleared to air 13 blocks down, so those tests lay their own stone floor.
```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.EnumMap;
import java.util.Map;
import java.util.Optional;

/**
 * One player's casting timers (spec §4): whether a spell may start now, when the pending perform or the no-targets
 * notice is due, and whether the arms are up. Times are game-time ticks supplied by the caller. Callers ask
 * {@link #readiness} before {@link #start} or {@link #noTargets}.
 */
public final class EvokingCast {
    /** Whether a spell may start now. */
    public enum Readiness {
        /** The spell may start now. */
        READY,
        /** Another cast's casting ticks are still running. */
        BUSY,
        /** This spell's interval has not passed. */
        COOLING
    }

    /**
     * Something the caster must do now: perform the pending spell, or tell the player no targets were found.
     *
     * @param kind what to do
     * @param spell the spell to perform; {@link EvokerSpell#FANGS} for the notice (only fangs look for targets)
     */
    public record Due(Kind kind, EvokerSpell spell) {
        /** Whether to run the pending perform or only tell the player. */
        public enum Kind {
            /** Run the pending spell. */
            PERFORM,
            /** Tell the player no targets were found. */
            NOTIFY_NO_TARGETS
        }
    }

    private static final long NEVER = Long.MIN_VALUE;

    private long castingUntil = NEVER;
    private final Map<EvokerSpell, Long> readyAt = new EnumMap<>(EvokerSpell.class);
    private Optional<EvokerSpell> pending = Optional.empty();
    private long performAt = NEVER;
    private boolean noticePending;
    private long noticeAt = NEVER;

    /**
     * Whether {@code spell} may start at {@code now}: {@code BUSY} while any cast's casting ticks run, else
     * {@code COOLING} while this spell's interval runs, else {@code READY}.
     */
    public Readiness readiness(EvokerSpell spell, long now) {
        if (now < castingUntil) {
            return Readiness.BUSY;
        }
        if (now < readyAt.getOrDefault(spell, NEVER)) {
            return Readiness.COOLING;
        }
        return Readiness.READY;
    }

    /**
     * Starts {@code spell} at {@code now}: the arms go up for its casting ticks, the perform is due after the warmup,
     * the spell's interval starts, and any scheduled notice is dropped.
     *
     * @throws IllegalStateException if {@link #readiness} is not {@code READY}
     */
    public void start(EvokerSpell spell, long now) {
        Readiness readiness = readiness(spell, now);
        if (readiness != Readiness.READY) {
            throw new IllegalStateException("cannot start " + spell + " at " + now + ": " + readiness);
        }
        castingUntil = now + spell.castingTicks();
        performAt = now + EvokerSpell.WARMUP_TICKS;
        pending = Optional.of(spell);
        readyAt.put(spell, now + spell.intervalTicks());
        noticePending = false;
    }

    /** Schedules the no-targets notice for one warmup after {@code now}; a later call moves it. */
    public void noTargets(long now) {
        noticePending = true;
        noticeAt = now + EvokerSpell.WARMUP_TICKS;
    }

    /**
     * What is due at {@code now}, each returned once: the pending perform once its warmup has passed, else the
     * notice once its delay has passed.
     */
    public Optional<Due> due(long now) {
        if (pending.isPresent() && now >= performAt) {
            EvokerSpell spell = pending.get();
            pending = Optional.empty();
            return Optional.of(new Due(Due.Kind.PERFORM, spell));
        }
        if (noticePending && now >= noticeAt) {
            noticePending = false;
            return Optional.of(new Due(Due.Kind.NOTIFY_NO_TARGETS, EvokerSpell.FANGS));
        }
        return Optional.empty();
    }

    /**
     * Whether the arms are up at {@code now}: the pure model of the casting-effect window (the GameTests observe it
     * through the synced effect).
     */
    public boolean isCasting(long now) {
        return now < castingUntil;
    }
}
```

```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

/**
 * The 13×13 block area a fang cast covers (spec §5), as offsets from the caster's block. The caster's block is always
 * on an edge: the facing vector {@code (−sin yaw, cos yaw)} is scaled so its larger component is ±1 and the center is
 * 6 blocks along it, so one center offset is exactly ±6 and the other sweeps −6…6 as the player turns.
 *
 * @param centerDx the square's center, east of the caster's block
 * @param centerDz the square's center, south of the caster's block
 */
public record FangSquare(int centerDx, int centerDz) {
    /** Half the square's side; the center is this far from every edge. */
    public static final int HALF = 6;

    /** The square's side in blocks. */
    public static final int SIZE = 2 * HALF + 1;

    /** How many cells get a fang: every cell but the caster's. */
    public static final int CELL_COUNT = SIZE * SIZE - 1;

    /**
     * One cell of the square.
     *
     * @param dx blocks east of the caster's block
     * @param dz blocks south of the caster's block
     * @param delayTicks the fang's warmup beyond the cast's: the Chebyshev distance from the caster minus one, so the
     *     fangs ripple outward one block per tick
     */
    public record Cell(int dx, int dz, int delayTicks) {}

    /**
     * The square for a caster facing {@code yawDegrees} (Minecraft yaw: 0 south, 90 west, 180 north, −90 east; any
     * finite value is accepted and wraps). Rounding is half-up, so the square is mirror-symmetric except at exact
     * ties, which no real yaw reaches.
     *
     * @param yawDegrees the caster's yaw
     * @return the square, with the caster's block on its edge
     * @throws IllegalArgumentException if the yaw is NaN or infinite
     */
    public static FangSquare of(double yawDegrees) {
        if (!Double.isFinite(yawDegrees)) {
            throw new IllegalArgumentException("yaw must be finite, got " + yawDegrees);
        }
        double yaw = Math.toRadians(yawDegrees);
        double fx = -Math.sin(yaw);
        double fz = Math.cos(yaw);
        double k = Math.max(Math.abs(fx), Math.abs(fz));
        return new FangSquare((int) Math.round(HALF * fx / k), (int) Math.round(HALF * fz / k));
    }

    /** The square's westmost dx. */
    public int minDx() {
        return centerDx - HALF;
    }

    /** The square's eastmost dx. */
    public int maxDx() {
        return centerDx + HALF;
    }

    /** The square's northmost dz. */
    public int minDz() {
        return centerDz - HALF;
    }

    /** The square's southmost dz. */
    public int maxDz() {
        return centerDz + HALF;
    }

    /** Whether the cell at {@code (dx, dz)} from the caster's block lies inside the square (edges included). */
    public boolean contains(int dx, int dz) {
        return dx >= minDx() && dx <= maxDx() && dz >= minDz() && dz <= maxDz();
    }

    /** Every cell but the caster's, row by row, each with its ripple delay. */
    public List<Cell> cells() {
        List<Cell> cells = new ArrayList<>(CELL_COUNT);
        for (int dz = minDz(); dz <= maxDz(); dz++) {
            for (int dx = minDx(); dx <= maxDx(); dx++) {
                if (dx != 0 || dz != 0) {
                    cells.add(new Cell(dx, dz, Math.max(Math.abs(dx), Math.abs(dz)) - 1));
                }
            }
        }
        return Collections.unmodifiableList(cells);
    }
}
```

```java
package io.github.willrieske.spellcraft.spell.rules;

import java.util.ArrayList;
import java.util.List;

/**
 * Where summoned vexes appear and how long they live (spec §6): the 40 cells whose Chebyshev distance from the
 * caster's block is 2 or 3, and the evoker's life formula.
 */
public final class VexRing {
    /** The nearest a vex spawns, per axis. */
    public static final int MIN_DISTANCE = 2;

    /** The farthest a vex spawns, per axis. */
    public static final int MAX_DISTANCE = 3;

    /** How many spawn cells there are: a 7×7 square minus its 3×3 middle. */
    public static final int COUNT = 40;

    /** How many vexes one cast summons. */
    public static final int SUMMON_COUNT = 3;

    /** The exclusive bound of the life roll: {@code lifeTicks} takes 0 … 89. */
    public static final int LIFE_ROLL_BOUND = 90;

    private static final int TICKS_PER_SECOND = 20;
    private static final int MIN_LIFE_SECONDS = 30;

    /**
     * A spawn cell, relative to the caster's block.
     *
     * @param dx blocks east
     * @param dz blocks south
     */
    public record Offset(int dx, int dz) {}

    private static final List<Offset> OFFSETS = ring();

    private VexRing() {}

    private static List<Offset> ring() {
        List<Offset> offsets = new ArrayList<>(COUNT);
        for (int dz = -MAX_DISTANCE; dz <= MAX_DISTANCE; dz++) {
            for (int dx = -MAX_DISTANCE; dx <= MAX_DISTANCE; dx++) {
                if (Math.max(Math.abs(dx), Math.abs(dz)) >= MIN_DISTANCE) {
                    offsets.add(new Offset(dx, dz));
                }
            }
        }
        if (offsets.size() != COUNT) {
            throw new AssertionError("ring size " + offsets.size());
        }
        return List.copyOf(offsets);
    }

    /** The spawn cell for a roll in {@code 0 … COUNT − 1}. */
    public static Offset offset(int index) {
        if (index < 0 || index >= COUNT) {
            throw new IllegalArgumentException("index must be 0-" + (COUNT - 1) + ", got " + index);
        }
        return OFFSETS.get(index);
    }

    /** The evoker's life for a vex: {@code 20 · (30 + roll)} ticks, 30 s to 119 s, for a roll in {@code 0 … 89}. */
    public static int lifeTicks(int roll) {
        if (roll < 0 || roll >= LIFE_ROLL_BOUND) {
            throw new IllegalArgumentException("roll must be 0-" + (LIFE_ROLL_BOUND - 1) + ", got " + roll);
        }
        return TICKS_PER_SECOND * (MIN_LIFE_SECONDS + roll);
    }
}
```

```java
/**
 * The evoker's look while casting (spec §7): the illager model's spellcasting arm pose, and where the evoker's hand
 * particles sit relative to its feet. Pure numbers; the client applies them.
 */
public final class EvokerPose {
    /** How far from the body center each hand particle sits, horizontally, at scale 1 (multiply by the scale). */
    public static final double HAND_DISTANCE = 0.6;

    /** How far above the feet the hand particles sit, at scale 1 (multiply by the scale). */
    public static final double HAND_HEIGHT = 1.8;

    private static final float SWAY_RATE = 0.6662F;
    private static final float ARM_SWAY = 0.25F;
    private static final float ARM_RAISE = (float) (Math.PI * 3.0 / 4.0);

    /**
     * A model arm's rotation, in radians.
     *
     * @param xRot forward sway
     * @param yRot twist (always 0)
     * @param zRot the raise, positive for the right arm and negative for the left
     */
    public record ArmRotation(float xRot, float yRot, float zRot) {}

    /**
     * One hand particle's offset from the body center; the other hand's is the negation.
     *
     * @param dx blocks east
     * @param dz blocks south
     */
    public record HandOffset(double dx, double dz) {}

    private EvokerPose() {}

    /** The illager spellcasting pose at {@code ageInTicks} for the right ({@code true}) or left arm. */
    public static ArmRotation armRotation(float ageInTicks, boolean rightArm) {
        float sway = (float) Math.cos(ageInTicks * SWAY_RATE) * ARM_SWAY;
        return new ArmRotation(sway, 0.0F, rightArm ? ARM_RAISE : -ARM_RAISE);
    }

    /**
     * Where one hand particle sits when the body faces {@code bodyYawDegrees} at {@code tick}; the other hand is
     * {@code (-dx, -dz)}. Multiply by the entity's scale.
     */
    public static HandOffset handOffset(float bodyYawDegrees, int tick) {
        double angle = Math.toRadians(bodyYawDegrees) + Math.cos(tick * SWAY_RATE) * ARM_SWAY;
        return new HandOffset(Math.cos(angle) * HAND_DISTANCE, Math.sin(angle) * HAND_DISTANCE);
    }
```

```java
package io.github.willrieske.spellcraft.spell;

import java.util.UUID;
import net.minecraft.world.entity.Entity;
import net.minecraft.world.entity.EntityReference;
import net.minecraft.world.entity.LivingEntity;
import net.minecraft.world.entity.OwnableEntity;
import net.minecraft.world.entity.animal.allay.Allay;
import net.minecraft.world.entity.player.Player;

/**
 * The one ally rule every spell uses (spec §3): what vanilla calls an ally (the player itself, the same team, a
 * tamed animal whose owner is the player, an allay that likes the player), plus the mobs the player summoned
 * ({@link AllyAttachments#SUMMONER}) and any other {@code OwnableEntity} the player owns, which vanilla's {@code
 * Vex} has but never reports through {@code isAlliedTo}.
 */
public final class Allies {
    private Allies() {}

    /** Whether a spell cast by {@code owner} must spare {@code other}. */
    public static boolean isAllyOf(Player owner, Entity other) {
        return owner.isAlliedTo(other) || ownedBy(owner.getUUID(), other);
    }

    /**
     * The cheap pre-check for callers that would otherwise have to look the owner up (Trailing runs it every tick
     * for every entity in a flame): {@code false} means {@link #isAllyOf} is false for every owner except through a
     * vanilla override this list does not know: team, {@code OwnableEntity}, {@code Allay}, the summoner attachment.
     * A modded entity with its own {@code considersEntityAsAlly} would need adding here.
     *
     * <p>Why those four are enough: {@code Entity.java:2879-2889} {@code isAlliedTo} is {@code this == other ||
     * considersEntityAsAlly(other) || other.considersEntityAsAlly(this)}, and the default {@code
     * considersEntityAsAlly} is a team check that is false when either side has no team ({@code Team.java:17},
     * {@code Entity.java:2887}). The vanilla overrides that ally a team-less entity to a player are {@code
     * TamableAnimal.java:209-222} (an {@code OwnableEntity}, {@code TamableAnimal.java:34}; its {@code getTeam()}
     * {@code :192-206} also borrows the owner's) and {@code Allay.java:160-163} (the player it likes); {@code
     * AbstractIllager} and {@code Evoker} ally only illagers and vexes. The summoner attachment is this mod's own
     * rule.
     */
    public static boolean mayHaveAllies(Entity other) {
        return other.getTeam() != null
                || other instanceof OwnableEntity
                || other instanceof Allay
                || other.hasData(AllyAttachments.SUMMONER);
    }

    private static boolean ownedBy(UUID owner, Entity other) {
        if (other.getExistingData(AllyAttachments.SUMMONER).filter(owner::equals).isPresent()) {
            return true;
        }
        if (other instanceof OwnableEntity ownable) {
            EntityReference<LivingEntity> reference = ownable.getOwnerReference();
            return reference != null && owner.equals(reference.getUUID());
        }
        return false;
    }
}
```

```java
import io.github.willrieske.spellcraft.spell.rules.EvokerSpell;
import java.util.Objects;
import net.minecraft.network.RegistryFriendlyByteBuf;

import net.neoforged.neoforge.network.codec.NeoForgeStreamCodecs;

/**
 * The client's "I pressed the key for this spell" (spec §4): the mod's one custom packet. A request, never a command:
 * {@link EvokingCaster#request} validates everything.
 *
 * @param spell the spell whose key was pressed
 */
public record EvokingRequest(EvokerSpell spell) implements CustomPacketPayload {
    /** The payload id, {@code spellcraft:evoking_request}. */
    public static final Type<EvokingRequest> TYPE = new Type<>(Spellcraft.id("evoking_request"));

    /** Writes the spell as its enum ordinal. */
    public static final StreamCodec<RegistryFriendlyByteBuf, EvokingRequest> STREAM_CODEC = StreamCodec.composite(
            NeoForgeStreamCodecs.<RegistryFriendlyByteBuf, EvokerSpell>enumCodec(EvokerSpell.class),
            EvokingRequest::spell,
            EvokingRequest::new);

    public EvokingRequest {
        Objects.requireNonNull(spell, "spell");
    }

    @Override
    public Type<? extends CustomPacketPayload> type() {
        return TYPE;
    }
}
```

```java
package io.github.willrieske.spellcraft.evoking;

import io.github.willrieske.spellcraft.Spellcraft;
import io.github.willrieske.spellcraft.effect.ModEffects;
import io.github.willrieske.spellcraft.spell.rules.EvokerSpell;
import io.github.willrieske.spellcraft.spell.rules.EvokingCast;
import io.github.willrieske.spellcraft.spell.rules.EvokingCast.Readiness;
import java.util.HashMap;
import java.util.Map;
import java.util.Optional;
import java.util.UUID;
import net.minecraft.core.Holder;
import net.minecraft.network.chat.Component;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.sounds.SoundEvent;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.sounds.SoundSource;
import net.minecraft.world.effect.MobEffect;
import net.minecraft.world.effect.MobEffectInstance;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.entity.player.PlayerEvent;
import net.neoforged.neoforge.event.server.ServerStoppedEvent;
import net.neoforged.neoforge.event.tick.PlayerTickEvent;

/**
 * Turns key presses into casts (spec §4): validates each request, keeps every player's pure {@link EvokingCast}
 * timers, and performs the pending spell on the player tick once its warmup has passed. The map is transient, like
 * {@code TrailLayer}'s trackers: dropped on logout and when the server stops, so a relog forgets cooldowns.
 */
@EventBusSubscriber(modid = Spellcraft.MODID)
public final class EvokingCaster {
    /** What a request did. Only {@code STARTED} changes anything. */
    public enum Request {
        /** No Evoking, dead, or a spectator. */
        IGNORED,
        /** Another cast's arms are still up. */
        BUSY,
        /** This spell's interval has not passed. */
        COOLING,
        /** Fangs with nothing to bite: only the notice, one warmup later. */
        NO_TARGETS,
        /** The cast started. */
        STARTED
    }

    /** Lang key of the action-bar notice. */
    public static final String NO_TARGETS_KEY = "message.spellcraft.no_targets";

    /** One player's timers and, for a pending fang cast, the snapshot taken at the press. */
    private static final class Casting {
        final EvokingCast cast = new EvokingCast();
        Optional<Fangs.Snapshot> snapshot = Optional.empty();
    }

    private static final Map<UUID, Casting> CASTINGS = new HashMap<>();

    private EvokingCaster() {}

    /**
     * Handles one key press for {@code spell} (spec §4): ignored without Evoking, while dead or as a spectator;
     * refused silently while busy or cooling; for fangs, scans for targets and schedules only the notice when there
     * are none; otherwise starts the cast (prepare sound, casting effect, timers).
     *
     * @param player the server-side player who pressed the key
     * @param spell the spell whose key was pressed
     * @return what the request did
     */
    public static Request request(ServerPlayer player, EvokerSpell spell) {
        if (!player.isAlive() || player.isSpectator() || !player.hasEffect(ModEffects.EVOKING)) {
            return Request.IGNORED;
        }
        ServerLevel level = player.level();
        long now = level.getGameTime();
        Casting casting = CASTINGS.computeIfAbsent(player.getUUID(), id -> new Casting());
        Readiness readiness = casting.cast.readiness(spell, now);
        if (readiness == Readiness.BUSY) {
            return Request.BUSY;
        }
        if (readiness == Readiness.COOLING) {
            return Request.COOLING;
        }
        if (spell == EvokerSpell.FANGS) {
            Optional<Fangs.Snapshot> snapshot = Fangs.snapshot(level, player);
            if (snapshot.isEmpty()) {
                casting.cast.noTargets(now);
                return Request.NO_TARGETS;
            }
            casting.snapshot = snapshot;
        }
        casting.cast.start(spell, now);
        playSound(level, player, prepareSound(spell));
        player.addEffect(new MobEffectInstance(castingEffect(spell), spell.castingTicks(), 0, false, true, false));
        return Request.STARTED;
    }

    /**
     * Runs {@link #tick} after each player tick.
     *
     * @param event the post-tick event for a player
     */
    @SubscribeEvent
    public static void onPlayerTick(PlayerTickEvent.Post event) {
        if (event.getEntity() instanceof ServerPlayer player) {
            tick(player);
        }
    }

    /**
     * One step for {@code player}: drops the entry without Evoking, else performs the pending spell or sends the
     * no-targets notice once due. Public so GameTests can step without waiting for a tick.
     *
     * @param player the server-side player to step
     */
    public static void tick(ServerPlayer player) {
        UUID id = player.getUUID();
        if (!player.hasEffect(ModEffects.EVOKING)) {
            CASTINGS.remove(id);
            return;
        }
        Casting casting = CASTINGS.get(id);
        if (casting == null) {
            return;
        }
        long now = player.level().getGameTime();
        casting.cast.due(now).ifPresent(due -> {
            switch (due.kind()) {
                case PERFORM -> perform(player, due.spell(), casting);
                case NOTIFY_NO_TARGETS -> player.sendOverlayMessage(Component.translatable(NO_TARGETS_KEY));
            }
        });
    }

    /**
     * Drops the entry of a player who left.
     *
     * @param event the logout event
     */
    @SubscribeEvent
    public static void onLogout(PlayerEvent.PlayerLoggedOutEvent event) {
        CASTINGS.remove(event.getEntity().getUUID());
    }

    /**
     * Drops every entry when the server stops (single-player loads one server per world in the same JVM).
     *
     * @param event the server-stopped event
     */
    @SubscribeEvent
    public static void onServerStopped(ServerStoppedEvent event) {
        CASTINGS.clear();
    }

    private static void perform(ServerPlayer player, EvokerSpell spell, Casting casting) {
        if (!player.isAlive()) {
            return;
        }
        ServerLevel level = player.level();
        boolean performed =
                switch (spell) {
                    case FANGS -> {
                        Optional<Fangs.Snapshot> snapshot = casting.snapshot;
                        casting.snapshot = Optional.empty();
```

```java
/**
 * The fang cast (spec §5): at the press, the square ahead of the caster and whether anything in it is a target; one
 * warmup later, a vanilla {@link EvokerFangs} on every cell of the square but the caster's, placed the way the
 * evoker places its own. Also the guard that keeps a player's fangs off the player's summons (spec §3).
 */
@EventBusSubscriber(modid = Spellcraft.MODID)
public final class Fangs {
    /** How far below and above the caster's feet the target scan reaches. */
    public static final int SCAN_HALF_HEIGHT = 6;

    /**
     * What the press fixed (spec §5): the fangs are placed from this, not from where the caster has walked to.
     *
     * @param dimension the level the caster stood in
     * @param feet the caster's block
     * @param square the square ahead
     * @param top the highest cell a fang's floor search starts from: max(feet, highest target) + 1
     * @param bottom the lowest cell the search reaches: min(feet, lowest target) − 1
     */
    public record Snapshot(ResourceKey<Level> dimension, BlockPos feet, FangSquare square, int top, int bottom) {}

    private Fangs() {}

    /**
     * The snapshot for a press by {@code caster}, or empty when no target stands in the square's columns within
     * {@link #SCAN_HALF_HEIGHT} blocks of the caster's feet.
     */
    static Optional<Snapshot> snapshot(ServerLevel level, ServerPlayer caster) {
        BlockPos feet = caster.blockPosition();
        FangSquare square = FangSquare.of(caster.getYRot());
        AABB box = new AABB(
                feet.getX() + square.minDx(),
                feet.getY() - SCAN_HALF_HEIGHT,
                feet.getZ() + square.minDz(),
                feet.getX() + square.maxDx() + 1,
                feet.getY() + SCAN_HALF_HEIGHT + 1,
                feet.getZ() + square.maxDz() + 1);
        List<LivingEntity> targets = level.getEntitiesOfClass(LivingEntity.class, box, e -> isTarget(caster, e));
        if (targets.isEmpty()) {
            return Optional.empty();
        }
        int highest = feet.getY();
        int lowest = feet.getY();
        for (LivingEntity target : targets) {
            int y = target.blockPosition().getY();
            highest = Math.max(highest, y);
            lowest = Math.min(lowest, y);
        }
        return Optional.of(new Snapshot(level.dimension(), feet, square, highest + 1, lowest - 1));
    }

    /** A target (spec glossary): an enemy a mob could attack, attackable, and neither the caster nor an ally. */
    // Entities compare by id (docs/api-notes.md §8); this asks "is it the caster".
    @SuppressWarnings("ReferenceEquality")
    static boolean isTarget(ServerPlayer caster, LivingEntity entity) {
        return entity != caster
                && entity.canBeSeenAsEnemy()
                && entity.attackable()
                && !Allies.isAllyOf(caster, entity);
    }

    /**
     * Places the fangs of {@code snapshot}: one per cell with a sturdy floor in the window, facing away from the
     * caster, with the cell's ripple delay. Nothing happens in another dimension than the snapshot's. Cells outside
     * the build limits or in unloaded chunks get none ({@link Level#isLoaded}; no chunk is loaded or waited on).
     *
     * @return true when the snapshot's level matched (so the cast sound plays), even if no cell had a floor
     */
    static boolean perform(ServerLevel level, ServerPlayer caster, Snapshot snapshot) {
        if (!level.dimension().equals(snapshot.dimension())) {
            return false;
        }
        BlockPos feet = snapshot.feet();
        for (FangSquare.Cell cell : snapshot.square().cells()) {
            int x = feet.getX() + cell.dx();
            int z = feet.getZ() + cell.dz();
            if (!level.isLoaded(new BlockPos(x, feet.getY(), z))) {
                continue; // outside the build limits, or its chunk is not loaded: no fang (spec §8)
            }
            findFloor(level, x, z, snapshot.top(), snapshot.bottom()).ifPresent(y -> {
                float angle = (float) Mth.atan2(cell.dz(), cell.dx());
                level.addFreshEntity(new EvokerFangs(level, x + 0.5, y, z + 0.5, angle, cell.delayTicks(), caster));
            });
        }
        return true;
    }

    /**
     * The evoker's floor search ({@code Evoker.createSpellEntity}): from {@code top} down to {@code bottom}, the first
     * cell whose block below has a sturdy top face, raised by the cell's own collision top (a slab, a carpet).
     */
    static OptionalDouble findFloor(ServerLevel level, int x, int z, int top, int bottom) {
        BlockPos pos = new BlockPos(x, top, z);
        while (pos.getY() >= bottom) {
            BlockPos below = pos.below();
            if (level.getBlockState(below).isFaceSturdy(level, below, Direction.UP)) {
                double topOffset = 0.0;
                if (!level.isEmptyBlock(pos)) {
                    VoxelShape shape = level.getBlockState(pos).getCollisionShape(level, pos);
                    if (!shape.isEmpty()) {
                        topOffset = shape.max(Direction.Axis.Y);
                    }
                }
                return OptionalDouble.of(pos.getY() + topOffset);
            }
            pos = below;
        }
        return OptionalDouble.empty();
    }

    /**
     * A player's fangs never bite the player's allies (spec §3). Vanilla already skips {@code isAlliedTo} allies; this
     * adds the summoner path (a vex the player called is no vanilla ally of the player). A fang whose caster has since
     * logged out has no owner and bites like a vanilla ownerless fang; accepted (a one-second window).
     *
     * @param event the incoming-damage event for any living entity
     */
    @SubscribeEvent
    public static void onIncomingDamage(LivingIncomingDamageEvent event) {
        DamageSource source = event.getSource();
        if (source.getDirectEntity() instanceof EvokerFangs
                && source.getEntity() instanceof Player owner
                && Allies.isAllyOf(owner, event.getEntity())) {
            event.setCanceled(true);
        }
    }
```

```java
    static void requestCodecRoundTrip(GameTestHelper helper) {

            RegistryFriendlyByteBuf buf =
```

Notes for the implementer:

- A mock player is never ticked by the server (`ServerPlayer.tick` skips `Player.tick`, so `PlayerTickEvent` never fires for it and its effects do not count down; docs/api-notes.md §19). So every delayed callback that expects a perform or a notice calls `step(player)` first, and the timings count from the tick on which `step` ran: a perform due at +20 places its fangs inside the `step` call at +20, after that tick's entity pass, so they first tick at +21. E19 is the one test that goes through the real subscriber, by posting `PlayerTickEvent.Post` itself.
- `loadPadding` (called inside `caster`) forces the padded box's chunks and fails with "setup: padded chunk … is not entity-ticking" if one is not: verify on the first run, then keep it. Without it a missing fang (`Fangs.perform` skips cells in unloaded chunks) would show up only as a short count.
- `toNether` cleans up through `GameTestSupport.whenDone`, not `helper.runBeforeTestEnd`: the latter runs only if the test is still going one tick before its timeout, so after an early `succeed()` it never runs.
- `helper.assertEntityPresent(EntityType, BlockPos)` and `assertEntityNotPresent(EntityType, BlockPos)` take relative positions (`GameTestHelper.java:611` and `:739`).
- E17's "deep hole" has no stone within the window (the pig's feet are 2 below the caster, so the window bottom is 3 below); the stone 6 below is outside it. The pig in the shallow hole stands on the stone 3 below the floor layer, so its fang stands one above that stone (2 below the floor layer) — exactly the pig's cell.
- In E6 the fangs are created directly (no cast, so no `step`) at the victims' exact positions with warmup 0, in the test's first tick. Each entity tick decrements the warmup first, so the bite (`warmupDelayTicks == -8`) lands on the fang's 8th tick, at +8; 12 ticks is enough. The vex nobody summoned is the control: it is bitten, so the summon is spared by the guard, not by vanilla.
- The server-stop test clears every player's cast, so it registers in the `evoking_server_stop` environment of its own; in `SHARED` it would drop the pending casts of the tests running beside it.

```java
/**
 * The vex summon (spec §6): three vanilla vexes beside the summoner, marked with the summoner attachment, living
 * 30–120 s as the evoker's do. Their target goals are replaced whenever one joins a server level (freshly summoned
 * or loaded from disk): they ignore the summoner and the summoner's allies and attack anything else within five
 * blocks.
 */
@EventBusSubscriber(modid = Spellcraft.MODID)
public final class VexSummons {
    /** How far a summoned vex looks for prey: its {@code FOLLOW_RANGE}. */
    public static final double AGGRO_RANGE = 5.0;

    private static final int TARGET_GOAL_PRIORITY = 1;

    private VexSummons() {}

    /**
     * Summons the vexes beside {@code summoner}: random ring cells one block up, iron swords from
     * {@code finalizeSpawn}, the summoner's team if it has one.
     *
     * @return the vexes, in spawn order
     */
    public static List<Vex> summon(ServerLevel level, ServerPlayer summoner) {
        RandomSource random = level.getRandom();
        PlayerTeam team = summoner.getTeam();
        BlockPos feet = summoner.blockPosition();
        List<Vex> vexes = new ArrayList<>(VexRing.SUMMON_COUNT);
        for (int i = 0; i < VexRing.SUMMON_COUNT; i++) {
            VexRing.Offset offset = VexRing.offset(random.nextInt(VexRing.COUNT));
            BlockPos pos = feet.offset(offset.dx(), 1, offset.dz());
            Vex vex = EntityTypes.VEX.create(level, EntitySpawnReason.MOB_SUMMONED);
            if (vex == null) {
                continue;
            }
            vex.snapTo(pos, 0.0F, 0.0F);
            vex.finalizeSpawn(level, level.getCurrentDifficultyAt(pos), EntitySpawnReason.MOB_SUMMONED, null);
            vex.setBoundOrigin(pos);
            vex.setLimitedLife(VexRing.lifeTicks(random.nextInt(VexRing.LIFE_ROLL_BOUND)));
            vex.setData(AllyAttachments.SUMMONER, summoner.getUUID());
            if (team != null) {
                level.getScoreboard().addPlayerToTeam(vex.getScoreboardName(), team);
            }
            level.addFreshEntityWithPassengers(vex);
            vexes.add(vex);
        }
        return vexes;
    }

    /** Installs the summoned goals on every marked vex that joins a server level, loaded or fresh. */
    @SubscribeEvent
    public static void onJoin(EntityJoinLevelEvent event) {
        if (event.getLevel() instanceof ServerLevel
                && event.getEntity() instanceof Vex vex
                && vex.hasData(AllyAttachments.SUMMONER)) {
            install(vex);
        }
    }

    /**
     * Replaces the vex's target goals with one: the nearest living thing within {@link #AGGRO_RANGE} that is
     * attackable and no ally of the summoner. The range is set first so the goal's constructor sees five; later
     * scans re-read the attribute anyway. Only for a marked vex: on an unmarked one {@code getData} would create the
     * mark with its default, so the only caller, {@link #onJoin}, checks {@code hasData} first.
     */
    static void install(Vex vex) {
        vex.targetSelector.removeAllGoals(goal -> true);
        AttributeInstance range = vex.getAttribute(Attributes.FOLLOW_RANGE);
        if (range != null) {
            range.setBaseValue(AGGRO_RANGE);
        }
        UUID summoner = vex.getData(AllyAttachments.SUMMONER);
        vex.targetSelector.addGoal(
                TARGET_GOAL_PRIORITY,
                new NearestAttackableTargetGoal<>(
                        vex, LivingEntity.class, true, (target, level) -> isPrey(level, summoner, target)));
    }

    /**
     * Whether a vex summoned by {@code summoner} may attack {@code target}: anything attackable that is no ally of
     * the summoner, and nothing while the summoner is not in {@code level} (offline or in another dimension). Public
     * for its GameTest in the {@code gametest} package.
     *
     * @param level the level the vex is in
     * @param summoner the UUID in the vex's summoner attachment
     * @param target the candidate target
     * @return whether the vex may take {@code target} as its target
     */
    public static boolean isPrey(ServerLevel level, UUID summoner, LivingEntity target) {
        if (!target.attackable()) {
            return false;
        }
        Player owner = level.getPlayerByUUID(summoner);
        return owner != null && !Allies.isAllyOf(owner, target);
    }
}
```

```java
    /** Every vex within 14 blocks of {@code center} in {@code level}. */
    static List<Vex> vexesAround(ServerLevel level, BlockPos center) {
        return level.getEntitiesOfClass(Vex.class, new AABB(center).inflate(14.0, 14.0, 14.0));
    }

    static int chebyshev(BlockPos a, BlockPos b) {
        return Math.max(Math.abs(a.getX() - b.getX()), Math.abs(a.getZ() - b.getZ()));
    }

    /**
     * Discards every vex around the caster's block when the test ends, whether it passes, fails or times out, so no
     * summoned vex flies on into the next batch.
     */
    static void discardLeftoverVexes(GameTestHelper helper) {
        whenDone(helper, () -> vexesAround(helper.getLevel(), helper.absolutePos(FEET)).forEach(Vex::discard));
    }

    /**
     * Keeps the first of three summoned vexes and parks it at {@code relative}: the others are discarded, and its
     * movement goals are removed so it hovers there while its target goal still runs. Parking fixes every distance
     * in the test, so targeting does not depend on where a wandering vex happens to be.
     */
    static Vex park(GameTestHelper helper, List<Vex> vexes, BlockPos relative) {
        helper.assertValueEqual(vexes.size(), VexRing.SUMMON_COUNT, "three vexes");
        vexes.subList(1, vexes.size()).forEach(Vex::discard);
        Vex vex = vexes.get(0);
        BlockPos at = helper.absolutePos(relative);
        vex.snapTo(at, 0.0F, 0.0F);
        vex.setBoundOrigin(at);
        vex.goalSelector.removeAllGoals(goal -> true);
        return vex;
    }
```

```java
import io.github.willrieske.spellcraft.particle.ModParticles;

/**
 * Which spell an entity is casting, read from vanilla's synced effect-particle list (spec §7): the server puts a
 * casting effect on the caster, and the effect's particle, one of {@link ModParticles}', reaches every client that
 * sees the caster. The accessor is opened by the access transformer (docs/api-notes.md §19).
 */
public final class CastingState {
    private CastingState() {}

    /** The spell {@code entity} is casting, if any. */
    public static Optional<EvokerSpell> of(LivingEntity entity) {
        List<ParticleOptions> particles = entity.getEntityData().get(LivingEntity.DATA_EFFECT_PARTICLES);
        if (particles.contains(ModParticles.CASTING_FANGS.get())) {
            return Optional.of(EvokerSpell.FANGS);
        }
        if (particles.contains(ModParticles.CASTING_VEXES.get())) {
            return Optional.of(EvokerSpell.VEXES);
        }
        return Optional.empty();
    }
```

```java
/**
 * The two casting keys (spec §2, §7). A press while the local player has Evoking sends an {@link EvokingRequest};
 * the server decides what it does. While Evoking is on, a casting key bound to the same key as vanilla's
 * swap-offhand (either of the two, if the user rebinds) swallows the swap: {@code ClientTickEvent.Pre} runs before
 * {@code Minecraft.handleKeybinds}, so clicks consumed here never reach it (docs/api-notes.md §19).
 */
@EventBusSubscriber(modid = Spellcraft.MODID, value = Dist.CLIENT)
public final class EvokingKeys {
    public static final KeyMapping.Category CATEGORY = new KeyMapping.Category(Spellcraft.id("spells"));

    /** Default F: vanilla's swap-offhand key, taken over only while Evoking is on. */
    public static final KeyMapping FANGS = new KeyMapping(
            "key.spellcraft.fangs",
            KeyConflictContext.IN_GAME,
            InputConstants.Type.KEYBOARD,
            InputConstants.KEY_F,
            CATEGORY);

    /** Default V: vanilla's F3-chord debug key, which needs F3 held. */
    public static final KeyMapping VEXES = new KeyMapping(
            "key.spellcraft.vexes",
            KeyConflictContext.IN_GAME,
            InputConstants.Type.KEYBOARD,
            InputConstants.KEY_V,
            CATEGORY);

    private EvokingKeys() {}

    @SubscribeEvent
    public static void onRegisterKeys(RegisterKeyMappingsEvent event) {
        event.registerCategory(CATEGORY);
        event.register(FANGS);
        event.register(VEXES);
    }

    @SubscribeEvent
    public static void onClientTick(ClientTickEvent.Pre event) {
        Minecraft minecraft = Minecraft.getInstance();
        LocalPlayer player = minecraft.player;
        boolean evoking = player != null && player.hasEffect(ModEffects.EVOKING);
        send(FANGS, EvokerSpell.FANGS, evoking);
        send(VEXES, EvokerSpell.VEXES, evoking);
        KeyMapping swap = minecraft.options.keySwapOffhand;
        if (evoking && (FANGS.same(swap) || VEXES.same(swap))) {
            while (swap.consumeClick()) {
                // swallowed: a casting key casts instead of swapping while Evoking is on
            }
        }
    }

    /** Drains the mapping's clicks; each one is a request while Evoking is on, and nothing otherwise. */
    private static void send(KeyMapping key, EvokerSpell spell, boolean evoking) {
        while (key.consumeClick()) {
            if (evoking) {
                ClientPacketDistributor.sendToServer(new EvokingRequest(spell));
            }
        }
    }
}
```

```java
    }
```

```java
import io.github.willrieske.spellcraft.Spellcraft;
import io.github.willrieske.spellcraft.spell.rules.EvokerPose;
import net.minecraft.client.entity.ClientAvatarEntity;
import net.minecraft.client.model.HumanoidModel;

import net.minecraft.client.renderer.entity.state.AvatarRenderState;
import net.minecraft.client.renderer.entity.state.HumanoidRenderState;
import net.minecraft.world.entity.Avatar;
import net.minecraft.world.entity.HumanoidArm;
import net.neoforged.api.distmarker.Dist;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;

import net.neoforged.neoforge.client.IArmPoseTransformer;
import net.neoforged.neoforge.client.renderstate.AvatarRenderStateModifier;
import net.neoforged.neoforge.client.renderstate.RegisterRenderStateModifiersEvent;

/**
 * The evoker's raised arms on a casting player (spec §7). {@code META-INF/enumextensions.json} adds the
 * {@code SPELLCRAFT_EVOKING} constant to {@code HumanoidModel.ArmPose} with {@link #PROXY}'s parameters (two-handed,
 * does not affect the offhand pose, this transformer); a render-state modifier sets both arms to it on every player
 * {@link CastingState} says is casting, which covers third person, other players and the inventory doll.
 */
@EventBusSubscriber(modid = Spellcraft.MODID, value = Dist.CLIENT)
public final class EvokingArmPose {
    /**
     * Named by {@code enumextensions.json}. {@code getValue()} forces the enum class to load (which applies the
     * extension) and throws a NullPointerException ("Enum not initialized ...") only if the JSON did not point a
     * {@code parameters.field} at this proxy (FML {@code EnumProxy.java:38-47}).
     */
    public static final EnumProxy<HumanoidModel.ArmPose> PROXY = new EnumProxy<>(
            HumanoidModel.ArmPose.class, true, false, (IArmPoseTransformer) EvokingArmPose::raise);

    private EvokingArmPose() {}

    /** The illager model's spellcasting pose for one arm. */
    static void raise(HumanoidModel<?> model, HumanoidRenderState state, HumanoidArm arm) {
        boolean right = arm == HumanoidArm.RIGHT;
        ModelPart part = right ? model.rightArm : model.leftArm;
        EvokerPose.ArmRotation rotation = EvokerPose.armRotation(state.ageInTicks, right);
        part.xRot = rotation.xRot();
        part.yRot = rotation.yRot();
        part.zRot = rotation.zRot();
    }

    @SubscribeEvent
    public static void onRegisterModifiers(RegisterRenderStateModifiersEvent event) {
        event.registerAvatarEntityModifier(new AvatarRenderStateModifier() {
            @Override
            public <T extends Avatar & ClientAvatarEntity> void accept(T avatar, AvatarRenderState state) {
                if (CastingState.of(avatar).isPresent()) {
                    HumanoidModel.ArmPose pose = PROXY.getValue();
                    state.rightArmPose = pose;
                    state.leftArmPose = pose;
                }
            }
        });
    }
}
```
